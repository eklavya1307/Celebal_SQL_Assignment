# Celebal SQL Assignment

## Overview

This repository contains the solutions for the Celebal Technologies SQL Assignment. The assignment consists of two tasks focused on SQL database design, data analysis, filtering, aggregation, business insights, and data validation.

---

## Task 1: Superstore Sales Analysis

### Objective

Analyze sales data using SQL with filtering, aggregation, sorting, business queries, and data validation.

### Tools Used

* MySQL
* Jupyter Notebook
* Python
* Pandas
* SQLAlchemy

### Key Operations

* Dataset Import
* Data Exploration
* WHERE Filters
* GROUP BY Aggregations
* Sales & Profit Analysis
* Top Products Analysis
* Top Customers Analysis
* Monthly Sales Trend Analysis
* Duplicate and NULL Value Validation

---

## Task 2: ShopEase Database Project

### Objective

Design and query an e-commerce database using SQL.

### Concepts Covered

* Table Creation
* Constraints
* Primary Keys
* Foreign Keys
* Indexes
* Joins
* Aggregate Functions
* CASE Statements
* Transactions
* Data Validation
